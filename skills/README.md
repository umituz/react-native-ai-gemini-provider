# React Native AI - Gemini Provider Skills

Claude Code skills for `@umituz/react-native-ai-gemini-provider` - Google Gemini AI integration.

## Installation

```bash
npx skills add /Users/umituz/Desktop/github/umituz/apps/mobile/npm-packages/react-native-ai-gemini-provider/skills/SKILL.md -g
```

## Usage

Say: **"Setup Gemini AI in my app"**

## Features

- Text generation (Gemini Flash, Gemini Pro)
- Structured JSON generation
- Streaming responses
- Multi-turn conversations
- Safety filters
- Function calling support

## Models

- **gemini-2.5-flash** - Fast responses, simple tasks
- **gemini-2.5-pro** - Complex reasoning, long content

## Pricing

Free tier: 15 requests/minute, 1,500 requests/day
Paid: Pay-per-use after free limits

See https://ai.google.dev/pricing
